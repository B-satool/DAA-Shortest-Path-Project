## Project

Project is an integral part for the CSE 317 course and it weighs 10% of the total grade. You’re
supposed to work on your projects in groups of 4 or 5 members. You need to choose your
partners yourself. Members can be across the sections.

## Scope of the project

Each group has to choose a computational (or a mathematical) problem for which you can find
at least two/three different algorithms (depending on the cardinality of your group). You need
to compare those algorithms for their design techniques, theoretical computational complexity,
implement them in the same language, test the implementations on the same machine, and
compare their time complexity empirically.

## Deliverables and grading

```
Project ideas with list of names of team members 1% Friday, April 17
Project presentation (max 10 minutes) 6% From Monday, May 4
Project reports 3% Friday, May 15
```
## Some possible project ideas

Following are some of the computational problems which you could use for your projects. Most of
these problems can be solved using many different algorithms therefore multiple teams (groups)
can choose a same project provided they choose at least one different algorithm.

- Shortest path problem
- Minimum spanning tree problem
- String matching problem
- Traveling salesperson problem
- Matrix multiplication problem
- Pairwise sequence matching problem
- Maximum flow in a flow network problem


## Project Report

Submit a well-structured report and it may have the following sections,

1. Introduction: Problem description, motivation and relevance in the real-world, formal/mathematical
    formulation of the problem, input and output specifications, etc.
2. Algorithm Description: For each paradigm, detailed explanation of its algorithm.
3. Theoretical Analysis: Expected theoretical time complexity (best, avg, worst) for each
    solution.
4. Implementation Details: Machine specification, programming language and libraries/tool
    used, range and size of test cases, input generation strategy, etc.
5. Results and Discussion: Runtime comparisons (maybe in forms of graphs and tables),
    comparison between theoretical and empirical results, strengths and weaknesses of each
    algorithm, etc.
6. Conclusion: Summary of findings, final insights on algorithm performance.
7. References: Proper citation of all external sources.
